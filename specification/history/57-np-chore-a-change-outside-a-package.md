#### 8.2.57 /np-chore: a change outside a work package, agreed 26 November 2026

Rulings by the author on 26 November 2026, after WP6.07's tag step stopped on a permission and a small change
to `.claude/settings.json` and `np-ship/wp.md` had no package to ride in. Two reviews on Opus 5.5 at high effort
read the proposal; the second found problems that this record answers. The questions were put through
`AskUserQuestion`, each with options and their consequences. The letter series continues at BG. BG6 and the changes to BG2, BG3 and BG5 were ruled the same day, after the second review.

| # | Decision | Consequence | Clause changed, and when |
|---|---|---|---|
| BG1 | **`/np-chore` is a skill that makes one change and opens its pull request.** The author asked for it with no limit on what the pull request may contain and no line between a chore and a package, "I prefer the flexibility" | A branch from `origin/main`, the change, a review, `just land`, and a `chore:` pull request the author merges; nothing tags it and no plan, package number or `/np-carry` stage is involved | §8.4.4; `.claude/skills/np-chore/`, in this commit |
| BG2 | *Its worktree refusal is amended by §8.2.58 BH1 (REV-297).* **Any session may run a chore, where no carry is running.** Offered the main session only (*the recommendation*), any session, and any session where no carry runs, the author chose the last | The skill refuses on a dirty tree, commits past `origin/main`, a worktree on a package branch, or a session started by `/np-carry`; the checks see this checkout alone, so the author's start of the session ensures that no carry runs elsewhere, and a helper, the reviewer or a worker hands back instead of running it; §8.2.56 BF11 stands, as no helper lands | §8.4.4; `.claude/skills/np-chore/` |
| BG3 | *Its rows for small findings and its failed land are amended by §8.2.58 BH1 (REV-296).* **A diff that is not Markdown alone is reviewed by `np-reviewer` before the pull request opens.** Offered limits on the content (*the recommendation*), no limit, and no limit with a review, the author chose the last.
