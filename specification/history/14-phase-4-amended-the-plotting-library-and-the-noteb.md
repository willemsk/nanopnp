#### 8.2.14 Phase 4 amended: the plotting library and the notebooks, agreed 22 October 2026

Rulings by the author, taken through `/phase-plan amend 4` while WP51, the user-testing protocol, was
planned and not started. The input is the author's request for a plotting library over every part of
the pipeline, to confirm by eye what each stage produces, and for notebooks in which to test the API
interactively; and REV-123 (CODE_REVIEW_012 AR-16 and AR-17), which found no plotting outside `gui/`
and no artefact that displays itself. Measured at `7f32b20`: the only figures are examples 03's and
04's, through the `examples` extra's Matplotlib; the GUI's pure-data view-models (`gui/geometry.py`
`ImageModel`, `gui/charge.py` `charge_image`, `gui/convergence.py` `ConvergenceModel`) sit above
every stage in the layer order; `post/export.py` `sample_at` returns a field's values as arrays; no
notebook tool is in the lock. The letter O is skipped, being read as zero. Package numbers from P1 on
supersede N6's.
