Workbench mockup A

One working session on the ClyA pore, 2WCD, through the four suites: Molecular, Continuum, Study and Analysis, with the project rail, the run queue and the changed count always on screen. It is built from the picks on the choice panels; where a pick was "either", this mockup differs from mockup B:

  • the changed count opens a pop-over (FR6 A)
  • a study opens as a form, its graph a switch away (RE1)
  • a run in progress is followed in the queue, unfolded wherever you are (RE2 A)
  • a comparison opens side by side, the difference a switch away (RE4)

Numbers are placeholders (x.xx): no artefact supplies them. The (r, z) views are not to scale. Parts of a later tool phase carry a banner and no working control. The bar under each screen moves through the session and to the same screen in the other mockup.
