C2 Molecular workspaceStrengths and weaknesses As in PyMOL or ChimeraX: one canvas always visible, docked panels, a command line.

Principle. The picture is the workbench. One central canvas shows every built stage as a layer; the areas are docked panels around it, and every panel action has a typed command.

PersonaStrengthsWeaknesses
P1 Method developersThe command line records a script of the session; selection links (S6) are natural, since everything is drawn on one canvas.The order of the pipeline is hidden; what is stale after an edit must be shown on the layers.
P2 Computational scientistsA typed command could replay as a case edit.Sweeps, many runs and the run queue have no natural home on one canvas; a docked panel is too small for a results explorer; the command line is a second surface to design.
P3 ExperimentalistsStarts from the molecule they know; clicking a residue is direct.No route: which panel next is left to them. A blank canvas before a structure says little; picking on a canvas needs a keyboard path.

Job 1 is short once the panels are known, but nothing orders them. Job 2 is click, edit and compare on one canvas. Live links (S6): residue and charge map drawn; a point probe drawn; geometry and parameters, cuts, and run and result not drawn. The 3D molecule and the (r, z) layers are different spaces, so the canvas changes mode between them.
