# Citing

If you use nanopnp, please cite both the software and the paper whose model it implements. The
repository carries a [`CITATION.cff`](https://github.com/willemsk/nanopnp/blob/main/CITATION.cff),
which GitHub renders as *Cite this repository*.

**The model.** K. Willems, D. Ruić, F. L. R. Lucas, U. Barman, N. Verellen, J. Hofkens, G. Maglia
and P. Van Dorpe, "Accurate modeling of a biological nanopore with an extended continuum
framework", *Nanoscale* **12**, 16775–16795 (2020),
[doi:10.1039/D0NR03114C](https://doi.org/10.1039/D0NR03114C).

**The software.** nanopnp has no archived release yet. A DOI-archived release and a JOSS paper are
part of v1.0 (QR-15). Until then, cite the repository and the commit you used. A run's manifest
records the version that produced it.
