# Comprehensive Code & Documentation Review Plan (Post-WP57)

**Target baseline:** `main` at `8a3488cd22df644bf5c50d78b36b0a3bddae9733` (after WP57 merge).  
**Excluded scope:** Existing PySide6 GUI (`src/nanopnp/gui/`, `packaging/`, `tests/**/test_gui*`), replaced by the Phase 5 browser workbench (`§8.2.12 M3`, `§8.2.17`).

## In brief

With the command-line and Python interface fixes of Phase 4 now on the main branch, this plan resolves the remaining architectural seams, implementation bugs, runtime bottlenecks, redundant code, and stale or wordy documentation before the phase closes as `v0.5.0`.

**What changes.** Six shallow module seams are deepened: stage-5 regions present one interface whether built from a structure contour or an idealised cylinder; cases own their file provenance and path rebasing without leaking private fields into the session; Poisson–Boltzmann solves return their assembled equations instead of rebuilding them after the solve; sweeps keep their resolved point keys so warm starts do not resolve parent cases a second time; post-processing caches symbolic property expressions; and command-line inspection routes through the session. Seven implementation bugs and gate loopholes (including non-finite Newton trial steps, mesh quality infinity coercion, and empty-wall statistics) are closed. Stale documentation (`current.md`, `README.md`, `getting-started.md`, findings logs) is updated and rewritten in clear Simplified Technical English (ASD-STE100).

**Cost.** Eighteen focused work items and four compaction checkpoints, executable in two to three days using sub-agents on Haiku and Sonnet for mechanical and module-scoped items.

**What could go wrong.** Touching stage 5, stage 6, or weak-form assembly could shift a cache key or a recorded benchmark number; `VER-61`, `VER-62`, and `VER-65` gate every commit so any drift is caught immediately.

**Your call.**

  *Recommendation:* run the code items (Items 1–14) as one code-review fix package and fold the documentation items (Items 16–21) into Documentation Increment 4.

### Grounding

#### 1. Architectural design flaws & shallow modules
- **Case lifecycle & private attribute leakage (`api/case.py`, `api/session.py`, `io/case.py`, `io/case_paths.py`, `pipeline/case.py`):**
  - `api/case.py:40-42` defines `_path: Path | None`, `_text: str | None`, `_base: Path | None`. `api/session.py:112-123` accesses `case._text`, `case._path`, and `case._base` directly when calling `run_document`.
  - `api/case.py:81-90` defines `__eq__` via `self.model_dump() == other.model_dump()` and `__hash__` via `hash(self.dumps())`, violating the Python data model whenever two equal models serialize differently or across processes.
  - `api/case.py:48-65`: `Case.load()` sets `case._base = source.resolve().parent` but keeps `case._path = source` un-resolved.
  - `api/case.py:105-145`: `Case.with_()` runs `substitute()` and `check_document()`, then checks `_rebased_paths()` and runs `substitute()` and `check_document()` a second time.
  - `api/case.py:297-323`: `Case.cylinder()` and `Case.from_structure()` call `_electrolyte()` (which calls `load_corrections(parameters)`) and then immediately call `load_corrections(parameters)` a second time to read `.dielectrics`.
  - Relative-path rebasing is split across four places: `api/case.py:333-343` (`_rebased_paths`), `pipeline/case.py:89-116` (`_absolute`, `_rebased`, `_correction_files`), `io/case_paths.py:489-512` (`input_paths`, `correction_paths`), and `api/sweep.py:168-193`.
- **Stage-5 region union & duplicate cylinder primitives (`geometry/region.py`, `geometry/pore.py`, `mesh/primitives.py`, `mesh/generate.py`, `mesh/ingest.py`, `plot/data.py`, `cli/__init__.py`):**
  - `geometry/region.py:227-256`: `read_region()` returns `RegionRecord | IdealisedRegionRecord`.
  - Downstream modules repeatedly branch on `isinstance(record, IdealisedRegionRecord)`: `mesh/generate.py:221-278` (branches twice), `mesh/ingest.py:596`, `plot/data.py:198-239`, `cli/__init__.py:602-610`.
  - `geometry/pore.py:22-101` (`CylinderPore`) and `mesh/primitives.py:209-229` (`CylindricalPoreGeometry`) store the same dimensions (`pore_radius_nm`, `membrane_thickness_nm`, `reservoir_radius_nm`); `CylinderPore.name_edges()` sets `edge.maxh = wall_h_nm` inside `geometry/`.
  - `plot/data.py:209-225`: the `IdealisedRegionRecord` branch in `region_drawing()` omits cis/trans reservoir outlines that `RegionRecord` draws.
- **Duplicate PB weak-form assembly (`physics/pb.py`, `physics/models.py`):**
  - `physics/pb.py:67-153`: `solve_pb_recorded()` builds the `H1` space, validates `measures.element_order`, resolves `ions` and `surface_charge_region`, assembles the PB weak form, solves it, and returns only `(potential, newton)`.
  - `physics/models.py:1376-1390`: `ElectrostaticModel.solve()` then reconstructs the `H1` space, regions, and residual form a second time to build `ModelSolution`.
- **Sweep repeated resolution (`sweep/plan.py`, `api/sweep.py`):**
  - `sweep/plan.py:555-570`: `_resolve_every_point()` calls `resolve()` on every sweep point, reloading correction YAML files and rebuilding physics models even when the swept axis is only `bias_V`.
  - `api/sweep.py:237-287`: `_parent_artefact()` reconstructs the parent case, calls `stored_upstream()`, calls `resolve(document, base=beside)` again, and computes `SolveStage.key()` from scratch.
- **QoI symbolic reconstruction & boundary checks (`post/qoi.py`, `post/indicator.py`, `post/reaction_flux.py`, `post/forces.py`, `physics/coefficients.py`, `physics/distance.py`):**
  - `post/qoi.py:85-144`: `indicator_currents()` rebuilds `NondimensionalCoefficients` and calls `species_flux()` per species in a loop without caching property expressions on `NondimensionalCoefficients` (`physics/coefficients.py:43-188`).
  - Boundary existence and measure checks are duplicated across `post/indicator.py:90-125`, `post/reaction_flux.py:36-79`, `post/forces.py:617-754`, and `physics/distance.py:17-65`.
- **CLI bypassing `Session` and `Case` (`cli/__init__.py`):**
  - `cli/__init__.py:289-292, 408-409, 815-875` imports `pipeline.run` and `pipeline.case` (`load_case`, `resolve`, `check_referenced_files`, `selected_stages`) directly in `_check`, `_explain`, and `_inspect` rather than going through `Case` and `Session`.

#### 2. Implementation flaws & numerical gates
- **`numerics/newton.py:216-220`**: `if trial_residual < current or at_minimum: forced = not trial_residual < current; break` accepts `NaN` or `Inf` `trial_residual` when `at_minimum` is reached, leaving `solution.vec` corrupted with `NaN` for subsequent iterations.
- **`mesh/quality.py:103-121`**: `np.nan_to_num(sicn)` and `np.nan_to_num(gamma)` convert `+inf` to `sys.float_info.max` (`~1.797e308`), which passes `min_sicn > 0.3` instead of failing the quality gate.
- **`mesh/generate.py:82-103`**: `wall_statistics(data, target_nm)` fails with raw `ValueError: attempt to get argmax of an empty sequence` if `"wall"` has 0 edges, and does not check `target_nm > 0`.
- **`charge/deposit.py:133-210, 307-327`**: `locate()` does not validate `cell_nm > 0` and allocates a dense rectangular grid `(high - low + 1)` that can explode on sparse coordinates; `Deposit.read()` does not validate array dimensions or finiteness.
- **`symmetry/reduce.py:83-108, 142-217`**: `ReducedMap.read()` does not check `harmonics.shape == (r_nm.size,)`, 1D monotonicity of `r_nm`/`z_nm`, or `n >= 1` in `reduce_map()`.
- **`geometry/contour.py:158-160, 274-286`**: `extract_contour()` assumes uniform `dr`/`dz` without checking axis uniformity/monotonicity; `resample()` accepts degenerate `total == 0` loops.

#### 3. Code efficiency improvements
- **`density/union.py:143-160, 239-287`**: `_stencils()` allocates 3D `meshgrid` arrays per unique width class without caching offsets by `m`; `deposit_ensemble()` recomputes frame-wide coordinate scaling and rounding inside the `for first in slabs:` outer loop (`O(slabs × frames)` instead of `O(frames)`).
- **`symmetry/reduce.py:183-204`**: `reduce_map()` runs a separate matrix multiplication `(matrix @ (delta * phase).T).T / areas` per harmonic `k` instead of batching harmonics per slab.
- **`geometry/contour.py:329-346`**: `enforce_spacing()` recomputes all segment lengths and calls `np.delete` in a `while` loop (`O(n²)`), replaceable by an `O(n log n)` min-heap over linked vertices.
